# TOEIC Drill

TOEIC の単語と英文法を解くための PWA ドリルです。ビルド処理のない静的サイトで、GitHub Pages で公開しています。
スマホではホーム画面に追加してアプリのように使え、オフラインでも動きます。PC ではキーボードだけで解けます。

公開版: https://ichirei13.github.io/toeic-vocabulary-app/

## できること

画面は「ホーム・演習・復習・グラフ・集中・設定」の 6 つです。

- **単語ドリル**: 英→日・日→英の 4 択、カードめくり、スペル入力。品詞・追加日・TEPPAN の番号範囲で絞り込めます。見出し語と例文は読み上げボタンで発音を聞けます。回答後には語源や TEPPAN での出方などの豆知識が出ます。
- **文法ドリル**: 4 冊の問題集から 3〜4 択。本・章で絞り込み、解説と和訳を折りたたみで見られます。
- **苦手と復習**: 間違えた問題は苦手リストに入り、間隔をあけて出し直します。完了画面から「苦手を解く」「復習を開く」へそのまま進めます。苦手単語は A4 の単語帳 PDF にできます。
- **ラベル**: 解いた問題に自分でラベル（🏷）を付け、ラベルごとに見返したり出題したりできます。
- **文法グラフ**: 問題・章・文法ルール・概念のつながりを、教材ごと（教材軸）と 13 の文法概念ごと（文法軸）の 2 通りで描きます。苦手がどこに集まっているかが見え、ノードから近い問題を解けます。レーダーではテーマごとの出来を比べ、テーマの問題をまとめて解けます。
- **記録**: 今日の目標・連続日数・解答ペース（即答の目標タイム）を記録します。
- **集中**: ポモドーロタイマー。
- **設定**: カラーテーマ（7 種類）、バックアップの書き出しと復元、Google ドライブとの手動同期（端末どうしで記録をそろえる）。

学習記録はブラウザの localStorage に保存し、サーバーには送りません（Google ドライブ同期を使ったときだけ、自分のドライブに保存します）。

## キーボード操作（PC）

| キー | 動作 |
| :--- | :--- |
| `1`〜`5`（`A`〜`E`） | 選択肢を選ぶ |
| `0` | わからない |

| `Esc` | 下から出るシートを閉じる |

## 開発

ビルドはありません。フォルダをそのまま静的サーバーで開けば動きます（例: `python3 -m http.server 8765`）。

- 本体は `index.html`・`home.js`・`js/*.js`・`css/`。DOM に触れない純粋なロジックは `src/*.js` にあり、Node で単体テストできます。
- 構成の詳しい説明と、壊れやすい約束事（JS の読み込み順、ファイルを足したときの一覧、保存とバックアップの形式など）は [`CLAUDE.md`](CLAUDE.md) にまとめています。変更の前に読んでください。
- 設計の経緯は `docs/superpowers/`（`specs/` が設計、`plans/` が実装計画）。

### テスト

```bash
pytest tests -q                 # ファイル一覧の整合、grammar.js の検証など（Python）
node --test tests/unit/         # src/*.js の単体テスト
NODE_PATH=$(npm root -g) node tests/<名前>.test.js   # ブラウザを動かすテスト（1 ファイルずつ）
```

- Python のテストは pytest コマンドで動かします（この開発機では `python3 -m pytest` が使えないため、Homebrew の `pytest` を使っています）。
- ブラウザのテストには Playwright が要ります（初回のみ `npm install -g playwright` と `npx playwright install chromium`）。

### 公開

`main` を GitHub に push すると、GitHub Actions（`.github/workflows/pages.yml`）が `tools/collect_site.py` で公開するファイルだけを集め、GitHub Pages に配信します。
公開するのは `sw.js` の `ASSETS` に載っているファイル（と `collect_site.py` の `EXTRA_FILES`）だけで、テスト・設計書・`next/`（試用版）は公開されません。
公開される中身は次のコマンドで確かめられます。

```bash
python3 tools/collect_site.py --list
```
