# 文法グラフビュー「レーダーチャート」モード設計

日付: 2026-11-20 / 状態: **実装済み（2026-11-20。実機 iPhone の確認は未実施）**

`2026-11-19-grammar-graph-axis-mode-design.md` への機能追加。
既存の力学ネットワーク図（`教材軸` / `文法軸`）に加え、模試の結果（TOEIC 公式認定証のアビリティーズメジャード）のように学習状況を俯瞰できる **「レーダーチャート」モード**（SVG レーダーチャート ＋ 項目別横棒グラフ ＋ スコアサマリー）を追加する。

## 1. 目的

- 力学ネットワーク図は概念・ひっかけ・問題のつながりを見るのに適している一方、**分野別の到達度・バランス・弱点の優先順位を模試の結果表のように数値でパッと見比べにくい**。
- 本機能では同じ `GRAMMAR_GRAPH` と学習記録（`grammarStats` / `grammarWeakData`）から、教材チップによる絞り込みに連動した総合サマリー・13 文法概念レーダーチャート・アビメ風横棒グラフを表示し、タップから既存の詳細シート・演習（「近い問題を解く」）へそのまま進めるようにする。

### 守ること

- 生成物 `data/grammar_graph.js`・`src/mastery.js` の既存判定や座標は変えない。
- 起動時の読み込みリクエスト数を増やさない（新規ファイル `src/graph-report.js` は `home.js` の `GRAPH_SCRIPTS` で遅延読み込みし、`index.html` には書かない）。
- オフラインで動く（`sw.js` の `ASSETS` と `CACHE` 版、`upload.py` の `FILES` を更新する）。
- 学習記録・バックアップ・Google ドライブ同期・他タブ再読込の形式と対象を変えない。`toeic_graph_mode_v1` のみ `'book' | 'grammar' | 'radar'` を保存する。
- レーダーチャート表示中および他モードの収束後は `requestAnimationFrame` を呼ばない。

## 3. 画面と集計の仕様

- **モード切替**: `.graph-mode` に `教材軸` (`book`) / `文法軸` (`grammar`) / `レーダーチャート` (`radar`) を並べる。
- **総合サマリー**: 選択中の教材範囲（すべて / 単冊）における `正答率（%）`・`着手済み（x/y問）`・`苦手（n問）`・`要復習（m問）` と、得意・要強化分野のワンタップ導線を表示する。
- **13 概念レーダーチャート**: `GRAMMAR_CONCEPT_ORDER` 順（12 時から時計回り）の 13 軸 SVG レーダー。`正答率` ポリゴン（塗り）と `着手率` ポリゴン（破線・表示切替可）および `80%` 目標ラインを描画する。頂点・ラベルのタップで詳細シートを開く。
- **軸ラベルの大きさ（2026-11-20 改訂）**: 実効 11px 以上にする。通常は半径 96・文字 12、SVG を入れる枠の幅が 385px 未満のときは詰めた配置（半径 76・文字 16、SVG に `is-compact`）。表示中に幅の区分が変わったら描き直す。当初は文字 10 のままで、375px 幅では実効約 6.9px だった。320px 幅の端末では実効約 9.5px になる（未対応）。
  真上・真下に近い軸（`|cos| < 0.3`。13 軸では真下の左右 2 軸を含む）は中央揃えにし、真上・真下ちょうどでないものは左右へ 8 ずつ外側にずらす。詰めた配置で「代名詞」と「形容詞・副詞」、「名詞」と「代名詞」のラベルが重なっていたため（375・768・900・1280px でラベルどうしが重ならないことをテストで確かめる）。
- **横棒グラフ（アビメ風）**: `文法概念 (13)` / `ひっかけ (12)` / `教材別 (4)` をタブで切り替え、`標準順` / `弱い順`（未着手は末尾、解答済み・苦手ありの中で正答率が低く苦手が多い順）で並べる。各行に 0〜100% バー・80% 目標線・正答率・解答問数・苦手/要復習バッジを表示し、タップで詳細シートを開く。
- **「苦手のみ」トグル連動**: ON のときは苦手問題を含む項目に絞り込んで表示する。
- **状態の判定（2026-11-20 改訂）**: 概念・ひっかけ・教材・総合の状態（色・バッジ）は、ネットワーク図・詳細シートと同じ `src/mastery.js` の `classifyMastery` で決める（判定順: 未着手 → 要復習 → 苦手 → 練習不足 → 定着 → もう少し。判定に使う率は `(正解 + 1) / (解答 + 2)`）。当初はレーダーだけ正答率のみで判定していたため、正答率 90%・苦手 2 問の分野が、棒グラフでは「良好」、詳細シートでは「苦手」と食い違っていた。画面に出す「正答率 %」は今までどおり `正解 / 解答`（詳細シートと同じ）。
- **得意・要強化の選び方（2026-11-20 改訂）**: 得意は、状態が「定着」か「もう少し」で、着手した問題が 3 問（`MASTERY_THRESHOLDS.minAnswers`）以上の分野から正答率が最も高いもの。要強化は、苦手登録がある分野か、着手 3 問以上で正答率 80% 未満の分野から、弱い順の先頭。1 問だけ解いて 100%（または 0%）になった分野を言い切らないため。

- **テーマの演習（2026-11-21 追加）**: レーダー表示中に開いた詳細シートの出題ボタンは、「近い問題を 30 問解く」ではなく「このテーマの全 N 問を解く」にする（教材軸・文法軸は今までどおり近い問題）。そのテーマの問題だけを打ち切らずに出し、順番は 苦手 → 未着手 → 克服 → 正解。苦手と未着手だけの「苦手と未着手の M 問を解く」も選べる（M が 0 か N と同じときは出さない。2026-11-21 改訂: 当初は「正解済みを除く」で、一度でも間違えた問題がずっと出題に残った）。教材で絞っていればその教材の分だけ。仕組みは「近い問題」と同じ（`state.nearDrill`・`toeic_near_drill_v1`、通常の出題の続きは書き換えない）で、`kind: 'theme'` を持ち、演習画面の上の表示が「〈テーマ〉の N 問」になる。
- **克服の基準（2026-11-21）**: 問題の状態は「苦手（苦手リストにある）／未着手／克服（間違えたことがあり、苦手リストに入っていない）／正解（一度も間違えていない）」の 4 つ。間違えた問題は必ず苦手リストに入り、復習で続けて正解すると外れる（`js/review-interval.js` の `updateWeakEntry`）ので、苦手リストから外れた問題を克服とみなす（苦手リストから手で消した問題も克服に数える）。詳細シートの問題一覧の「誤答あり」は「克服」に改めた（`src/graph-detail.js` の `statusOf`）。正答率と状態（定着・もう少し・苦手など）の計算は変えない。
- **横棒の内訳（2026-11-21）**: 横棒は正答率ではなく、問題の内訳（正解＝緑・克服＝青・苦手＝赤・未着手＝灰）を問題数に対する割合で積み上げる（`computeGraphReport` の `neverMissed`・`overcome`・`weak`・`untouched`。合計は `total`）。棒の下に内訳の数、一覧の上に凡例を出す。右の正答率 % はそのまま。80% の目標線は内訳の棒には意味がないので外した（80% はレーダーの点線で見る）。
- **ホームの入口（2026-11-21）**: ホームの文法のタブに「🕸 文法グラフ」のカードを置き、正答率と苦手の数を出す。「レーダーで見る」を押すと、前回のモードによらずレーダーで開く（`toeic_graph_mode_v1` を `radar` にしてから開く）。起動時の読み込みを増やさないため、カードはグラフのデータを読まず手元の記録だけで数える（分野ごとの「要強化」は出さない）。
