# 文法問題 1 問分析の高精度化と文法グラフ v4 — 設計

## 背景と目的
従来の文法グラフ（`version: 3`）では、`English_study` の `concept_extractor.py` / `trap_extractor.py` が章名・ルール名・解説文の日本語キーワード部分一致だけで概念（13 種）・ひっかけ（12 種）を付けていた。その結果、以下の課題が生じていた：
- 全 983 問中 79.9%（785 問）が Trap 0 件で、実質『金の文法』以外でひっかけ分析が機能していなかった。
- 部分一致による誤爆（`Trap_12` の約 6 割が関係詞以外の章への誤付与など）が多数発生していた。
- 複合章やフォールバック（未一致→`SVOC`）により、主論点と補助知識の区別がなく配置や類似問題推薦の精度が頭打ちになっていた。

そこで、**全 983 問を問題文・選択肢（ダミー含む）・正解・解説まで含めて 1 問ずつ精読・構造化分析し、`question_analysis.json` を正典として Vault と文法グラフ v4 へ流す設計**へ刷新する。

## 確定仕様

### 1. 16 概念（時計回り順）
従来の 13 概念から「助動詞・仮定法」を分離し、「動詞・形容詞の語法」と「前置詞のコアイメージと用法」を新設した 16 概念とする。16 軸化により、レーダーチャートおよび文法軸円周配置が左右対称になる。

1. `SVOC（文の骨格）`（短縮: `SVOC`）
2. `動詞・形容詞の語法`（短縮: `語法`）※新設
3. `能動態と受動態`（短縮: `受動態`）
4. `分詞（現在分詞・過去分詞）`（短縮: `分詞`）
5. `動詞の時制と相`（短縮: `時制・相`）
6. `助動詞`（短縮: `助動詞`）※分離
7. `仮定法`（短縮: `仮定法`）※分離
8. `動名詞 vs 不定詞`（短縮: `動名詞/不定詞`）
9. `名詞の役割（主語・目的語・補語）`（短縮: `名詞・冠詞`）
10. `代名詞の格と用法`（短縮: `代名詞`）
11. `形容詞と副詞の修飾関係`（短縮: `形容詞・副詞`）
12. `関係代名詞・関係副詞`（短縮: `関係詞`）
13. `比較級・最上級`（短縮: `比較`）
14. `接続詞 vs 前置詞の識別`（短縮: `接続詞`）
15. `前置詞のコアイメージと用法`（短縮: `前置詞`）※新設
16. `倒置・強調・並列構造`（短縮: `倒置・強調`）

### 2. 18 ひっかけ（Trap）
既存の `Trap_01`〜`Trap_12` を維持し、4 教材全体を網羅するため以下 6 種を追加する：
- `Trap_13_助動詞_have_ppと仮定法の時制ズレ`
- `Trap_14_動名詞と不定詞の目的語・意味の違い`
- `Trap_15_比較構文の対象一致・強調語・慣用表現`
- `Trap_16_前置詞の期限・継続・コアイメージの混同`
- `Trap_17_動詞・形容詞の語法とペア表現の罠`
- `Trap_18_語順・倒置・間接疑問・強調の罠`

### 3. 1 問分析正典（`English_study/question_analysis.json`）
各問題（アプリ収録 983 問）に対して以下を保持する：
- `app_id`: `toeic_practice` の問題 ID
- `book`: `sekai` / `kin` / `polaris2` / `toplevel`
- `vault_file`: 対応する Vault 問題ノート相対パス（`matchQuestions()` で確定）
- `vault_practice_id`: Vault 側の `practice_id`
- `primary_concept`: 主概念（16 概念から必ず 1 つ）
- `secondary_concepts`: 副概念（16 概念から 0〜2 つ、主概念と重複不可）
- `traps`: ひっかけ（18 Trap から 0〜2 つ）
- `solve_type`: 解法タイプ（`品詞・語形` / `文構造` / `語法・コロケーション` / `意味・文脈`）
- `point`: 15〜55 字のネタバレなし 1 行着眼点

### 4. 文法グラフ v4（`data/grammar_graph.js`）
- `version: 4`
- `edges` 種別：`0: 親子` / `1: 主概念` / `2: Trap` / `3: 副概念`
- `members` 集計：エッジ種別 `0, 1, 2` のみを辿り、`3`（副概念）は概念ノードの `members` に含めない。これによりレーダーチャート・`mastery.js`・概念詳細の問題数の合計が **983 問ぴったり**で一致する。
- 問題メタデータ：`solveTypes`（文字列配列）、`qSolveType`（問題序数→添字、無ければ `-1`）、`qPoint`（問題序数→着眼点文字列）。
- **力学（`src/graph-force.js`）**：主概念（type 1）には強い引力、副概念（type 3）には弱い引力（`secondaryConceptStrength`）を与え、主概念の島をくっきり分離しつつ複合問題を島の縁へ配置する。
- **近い問題（`src/graph-near.js`）**：Trap (2.0) ＞ 主概念 (1.2) ＞ 副概念 (0.4) の重みで類似問題・類題を推薦する。
- **詳細シート（`src/graph-detail.js` / `js/graph-sheet.js`）**：問題ノードを開いたときに解法タイプ・主概念/副概念/Trap チップ（タップで該当ノードへジャンプ可能）・1 行着眼点を表示する。
