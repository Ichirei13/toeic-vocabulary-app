# 苦手単語の単語帳PDF（紙に印刷）— 設計

作成日: 2026-11-05 / 状態: 設計の合意済み・実装前

## 目的

苦手リストの単語を、紙に印刷して覚えやすい形の単語帳PDFにして出力する。
画面でテストを解き続けるだけでは定着しにくい単語を、「隠して思い出す → 手で書く → 答え合わせ」の流れで反復できるようにする。

## 合意した方針

| 項目 | 決めたこと |
|---|---|
| 使い方 | 紙に印刷する（GoodNotes などへの取り込みは想定しない）。 |
| 対象 | 苦手リストのシートで今選んでいるモード（英→日 / 日→英 / カード / タイプ）の苦手単語。文法の苦手は対象外。 |
| 構成 | 1セット30語。1セットは ①暗記ページ（1枚）が基本で、オプションで ②確認テストページ・③答えページ（各1枚）が続く。語数が30を超えたら、次のセットに続ける。 |
| オプション | 出力前に2つ切り替えられる。「日本語を赤字にする」（既定: オン）と「確認テストをつける」（既定: オン）。選んだ状態は端末に覚えさせる。 |
| 出力のしかた | 印刷用のHTMLを別タブに作り、印刷ダイアログを開く。「PDFとして保存」で出力する。ライブラリは足さない。 |
| 今回やらないこと | 例文つきレイアウト、正誤の回数の表示、文法の単語帳、用紙サイズや語数（30語）の設定。 |

## 設計

### 1. 出力するページ

1セット（最大30語）は、確認テストがオンなら3ページ、オフなら1ページ（暗記ページだけ）。PDF全体は、セット1、セット2、…と続く。

**オプション**（2つとも、苦手リストのシートで「単語帳PDF」ボタンの隣に置く）

| オプション | オン | オフ |
|---|---|---|
| 日本語を赤字にする | 暗記ページの日本語を赤字にする（赤シートで隠せる）。 | 日本語を黒字にする。折り線は残るので、折って隠すことはできる。 |
| 確認テストをつける | セットごとに、暗記ページのあとに②確認テストと③答えを付ける。 | 暗記ページだけを出す（セットごとに1枚）。 |

赤字のオプションが効くのは暗記ページの日本語だけ。確認テストの日本語は、赤字のオプションに関係なく黒字（赤シートで問題文が消えないようにするため）。答えページの日本語は、赤字のオプションに従う。

**① 暗記ページ**（A4縦、15語 × 左右2ブロック）
- 各ブロックの列は「行番号｜英語（品詞）｜日本語」。英語と日本語の境目に薄い点線の折り線を引く。
- 日本語は、赤字がオンのとき赤字（朱赤。赤シートで消える色）、オフのとき黒字。英語と品詞は黒・灰色。
- 各行は2段。上段に英語と日本語、下段に左から周回チェック（□□□）と、メモ用の細い罫線を置く。
- 行の高さは 15mm 固定。15行 × 15mm ＋ 見出し行で、A4 の余白を引いた領域（267mm）に収まる。
- 語の並びは、復習日が近い順（`entry.due` の昇順）。

**② 確認テストページ**（確認テストがオンのときだけ）
- ①と同じ30語を、ランダムに並べ替える。左右2ブロックに15語ずつ。
- 各ブロックの列は「行番号｜日本語｜英語を書く空欄」。日本語は黒字にする（赤シートで隠さないため）。
- 行の高さは 15mm。空欄に手で書ける広さを取る。

**③ 答えページ**（確認テストがオンのときだけ）
- ②と同じ並びで、「行番号｜英語｜日本語」を並べる。左右2ブロック、行の高さは 9mm の詰めた表。

**ヘッダー（全ページ）**: 「TOEIC 苦手単語帳（モード名）」、出力日、セット n/N、ページの種類（暗記・テスト・答え。確認テストがオフのときは種類を出さない）、通しのページ番号。

### 2. 紙向けのページ仕様

- `@page { size: A4 portrait; margin: 15mm 10mm 15mm 20mm; }` 左の余白を広くして、穴あけ・ファイリングに備える。
- 赤字は `print-color-adjust: exact`（`-webkit-` つきも）で、背景や色を省かれないようにする。
- 1ブロックの幅は約 87mm（本文幅 180mm から、ブロック間の 6mm を引いて 2 で割る）。
- 日本語の意味が長い語（約 20 文字を超える）は、その行だけ文字を小さくする。行の高さは変えない。語データの意味の最長は 65 文字。
- 表と各行には `break-inside: avoid` を付け、行が2枚にまたがらないようにする。
- 品詞は先頭の1〜2字に縮める（名詞→名、動詞→動、形容詞→形、副詞→副、動詞句→動句、名詞句→名句、形容詞句→形句、表現・句・表現→句）。知らない品詞は、そのまま出す。

### 3. ファイルと読み込み

DOM に触らない部分と、画面に触る部分を分ける。

- 新規: `src/wordbook.js` — 純粋ロジック（Node の単体テストあり）。ブラウザでは `StudyCore.*`、node では `require` で使う（`src/pace.js` と同じ書き方）。
  - `selectItems(...)`: 苦手の記録と語データから、出力する語の配列を作る（語データに無いキーは捨てる）。
  - `sortByDue(items)`: 復習日の昇順に並べる（同じなら追加日の古い順、さらに同じなら見出し語のABC順）。
  - `chunk(items, 30)`: 30語ずつのセットに分ける。
  - `shuffle(items, rng)`: 並び替え。乱数は引数で差し替えられる（テスト用）。
  - `shortPos(p)`: 品詞の略記。
  - `normalizeOptions(v)`: 保存されていた値を `{ red, test }`（どちらも真偽値）に直す。真偽値でなければ、その項目はオン。
  - `buildDocument({ items, modeLabel, date, options })`: 印刷用のHTML全体（`<style>` を含む文字列）を返す。`options` は `{ red, test }`。語の文字列は必ずエスケープする。
- 新規: `js/weak-print.js` — 画面側。苦手リストシートの「単語帳PDF」ボタンの処理と、別タブでの印刷だけを持つ。
  - `window.open` はクリックの中で同期的に呼ぶ（ポップアップブロックを避ける）。開いたタブに HTML を書き込み、読み込みが済んだら `print()` を呼ぶ。
  - タブを開けなかったときは、その場でメッセージを出す。
- 変更: `js/weak-list.js` の `renderWordWeakList()` に、オプションの2つのチップ（「日本語を赤字」「確認テスト」。既存の `.chip` と `active` の見た目）と「単語帳PDF」ボタンを足す。クリックは、同ファイル末尾の委譲ハンドラ（`data-` 属性で振り分ける）に足す。チップを押したら、状態を反転して保存し、シートを描き直す。苦手が0件のときは出さない。
- 変更: `js/word-stats.js` の `state` の初期値に `wordbookRed: true`、`wordbookTest: true` を足す。
- 変更: `js/settings.js` の `settingsSnapshot()` のキーに `wordbookRed`、`wordbookTest` を足し、`restoreSettings()` で真偽値として検証して戻す（`weakSort` と同じ流れ。保存値は信用せず、真偽値でなければオン）。
- 登録先: `index.html`（script と、読み込み順のコメント）、`sw.js` の ASSETS（キャッシュ名の版も上げる）、`upload.py` の FILES。
  `tests/test_file_lists.py` が、sw.js と upload.py の一致を確かめる。
- 読み込み順: `src/wordbook.js` は `src/pace.js` の次、`js/weak-print.js` は `js/weak-list.js` の次。

### 4. データの流れ

苦手リストのシート →（「単語帳PDF」を押す）→ `state.weakListMode` のモードと、`state.wordbookRed` / `state.wordbookTest` のオプションを読む → `wordWeak(mode)` と `RAW_WORDS` から語を集める → 復習日順に並べ → 30語ずつに分ける → セットごとにHTML（確認テストがオンなら3ページ分、オフなら1ページ分）を作る → 別タブに書き込んで印刷ダイアログを開く。
保存するのは、オプションの2つの真偽値だけ。苦手の記録は変更しない。

### 5. エラーと端の場合

| 場合 | 動き |
|---|---|
| 苦手が0件 | ボタンを出さない（既存の「苦手な単語はありません」のまま）。 |
| 語数が30の倍数でない | 最後のセットの最後のブロックは、空の行を罫線だけで残す（枠は同じ）。 |
| ポップアップを開けない | 「別タブを開けませんでした。ポップアップを許可してください」と表示する。 |
| 語データに無いキー | 苦手リストの表示と同じく、読み飛ばす（`weak-list.js` の既存の扱いに合わせる）。 |

## 検証

- **単体テスト**（`tests/unit/wordbook.test.js`）: 並び順（復習日・同日の決め方）、30語ごとの分割（29・30・31・60語）、シャッフルが同じ語の組を保つこと（乱数を固定して並びも）、品詞の略記、HTML の特殊文字のエスケープ、ページ数（確認テストがオンならセット数 × 3、オフならセット数 × 1）、`normalizeOptions`（真偽値以外はオン）。赤字のオン・オフで、暗記ページの日本語の色が変わり、確認テストの日本語は変わらないこと。
- **設定の保存**: オプションの選択が `settingsSnapshot()` に入り、開き直しても戻ること。壊れた保存値（文字列や null）でもオンに戻ること。
- **ファイル一覧のテスト**: `tests/test_file_lists.py` が通ること。
- **画面での確認**: ブラウザの印刷プレビューで、A4で1ページに収まること、折り線・赤字が出ること、意味の長い語で崩れないこと。可能なら、実際に赤シートで日本語が消えることを手元で確かめる。
- **未確認のこと**: iPhone の Safari で、印刷からPDF化できること（共有→プリント→ピンチ操作）。実装後に確かめ、だめなら別の出し方を相談する。
