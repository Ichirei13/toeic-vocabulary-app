# サブエージェント用プロンプト（豆知識の執筆）

1バッチ（30語）につき1回、サブエージェントに渡す。`{入力}` `{出力}` を実際のパスに置き換える。
サブエージェントはプロジェクトのファイルを触らず、作業フォルダの JSON だけを書く。

````
TOEIC 単語アプリ用の「覚えやすい豆知識」を書いてください。

入力: {入力}（タブ区切り: 見出し語 / 意味 / 品詞 / 例文。1行1語、30語）
出力: {出力} に、{"見出し語": "豆知識", ...} の JSON オブジェクト1つだけを書く。
キーは入力の見出し語と完全一致、全語分。

豆知識の中身（日本語、TOEIC 受験者向け）:
- 中心は「語源（接頭辞・語根・由来）」と「TOEIC での出方（頻出コロケーション、語法・前置詞、品詞の区別、
  出やすい文脈・パート、紛らわしい語との区別）」。
- 1語につき 1〜2文、全体で 80 文字前後（長くても 120 文字以内）。覚えるきっかけになることが目的。
- 事実に自信のないことは書かない。語源は確かなものだけ。自信がなければ語源は書かず、語法や区別のポイントだけにする。
- TOEIC での出方は「〜の形でよく使われる」のような傾向の言い方にとどめる。
  「出題率○%」「必ず出る」など根拠のない数字・断定は禁止。
- 語ごとに表現を変える。「〜でよく使われる」「〜の文脈で出やすい」だけで終わる中身のない決まり文句は避け、
  具体的なコロケーション・前置詞・品詞の違いを優先する（例: recommend は doing か that 節を取る、など）。
- 入力が daily の語（記事由来の語や、mounting pressure のような複数語の句）のときは、TOEIC での出方を無理に書かない。
  語源・語のイメージ・一緒に使う語（コロケーション）を中心にし、TOEIC に関係する語だけ出方を添える。
  句は、構成する語の語源や意味から覚えるヒントを書く。
- 語呂合わせは無理に作らない。意味や例文の言い換えだけの文は不可。HTML タグや改行は入れない。
- 書式の例:
  "substantial": "sub-(下に)+stance(立つもの)で、土台がしっかりしている→「相当な」。substantial increase や substantial amount の形で出やすい。"

書き終えたら、python3 -c 'import json;d=json.load(open("{出力}"));print(len(d))' で読めて 30 語あることを確認して報告する。
プロジェクトのファイルは一切変更しないこと。
````
